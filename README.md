在真實台北市空照地圖上狙擊噁男的俯視狙擊遊戲。你是暗網上的頂尖駭客兼職業狙擊手，對一般仇殺沒興趣，只接被性騷擾、跟騷、偷拍的女性與女學生的委託。法律管不了的噁男，由你從幾百公尺外解決。

🎮 **線上試玩：** https://xiang0723.github.io/project_game_skykiller/

> 不用安裝、不用註冊，用電腦瀏覽器就能玩（手機也能開，但瞄準比較吃力）。進度存在你自己的瀏覽器裡。

## 遊戲特色

- **真實的台北市地圖**：內政部國土測繪中心的正射空照圖加上 OpenStreetMap 的真實路網，涵蓋台北市 12 個行政區。選好行政區後，每一局都會在區內隨機挑一塊市區當狙擊場，每次的街景都不一樣。
- **上帝視角狙擊**：從正上方俯瞰街道，拖曳地圖瞄準，縮放就是狙擊鏡倍率。×18 看得到上衣顏色，×19 看得到帽子，×21 以上看得到身體部位。
- **真實的彈道**：你從地圖上固定的狙擊位置開槍。距離越遠，子彈飛得越久，移動中的目標要抓提前量。橫風會把子彈吹偏，準星旁的藍點會標出風偏修正後的落點，把噁男對準藍點就打得中；瞄準輔助也會幫你補上大部分提前量，手機也能玩。
- **暗網委託**：委託人有五百多種暱稱和五百多種身分（國小生、國高中生、大學生、上班族、各行各業）隨機組合，會描述噁男的惡行，情節從輕微騷擾到極度噁心都有，由上百種行為、地點與後續組合出上萬種不重複的描述，並附上噁男的兩項特徵（帽子顏色、上衣顏色）與出沒的行政區。
- **指定部位與順序**：委託人會要求「一槍爆頭」，或是「先打胯下、再打兩隻手掌、最後爆頭」這類要求。全身 21 個部位都可能被指定，可以重複，甚至先打死再補槍（鞭屍）。全部照順序打中是完美達成、拿全額；順序不對或只打中部分，就依完成度領取。
- **找出噁男**：現場有上百個路人，還有同上衣不同帽子、同帽子不同上衣的誘餌，要放大仔細比對帽子和上衣。槍聲會讓附近的人四散逃跑，誤傷路人會被扣酬勞和聲望。
- **彈藥庫**：9 種特性不同的子彈：標準彈、高速彈、抗風彈、競賽級精準彈、擴張彈、亞音速彈、麻醉彈（只讓人昏睡不動，不濺血、不算部位，誤射路人照扣）、破片彈（打哪都致命但會波及路人）、導引彈（自動修正風偏與提前量）。出擊前自己挑要帶哪些，最多 10 發，任務中按 1～9 切換。
- **裝備庫**：狙擊鏡、彈藥袋、腳架、槍管穩定器、快速槍機、彈道電腦、消音器、監視器入侵 8 項裝備，可以升級，但每項都有上限，準度還是要靠自己。高倍率下準星會隨呼吸晃動，按住 Shift 屏息。
- **學生委託**：委託人是學生的案子酬勞很少，也沒有小費；有些學生付不起錢，只能發免費委託，但完成後聲望加 3 倍。
- **聲望**：受害者付不起高價，酬勞不多。聲望越高，完成委託的小費越多、買東西越便宜；誤傷路人讓聲望變成負的，東西就會變貴。

## 怎麼玩

1. 在 **暗網終端** 的「委託」頁挑一件委託。一次 4 件，做完的會標示「結案」（成功／失敗），4 件都結案才會收到新的一批；不想做的可以刷新換掉，每次扣 5 聲望。出沒地點、噁男特徵和現場狀況是加密的，花 $5 解密才看得到。看清楚噁男的特徵、出沒地區和委託人的要求後接案，再到「出擊準備」挑選要帶的彈藥。
2. 進入狙擊場後，**藍圈** 是你的位置，**黃色虛線圈** 是噁男活動範圍，**黑色粗框** 是地圖邊界。
3. 拖曳地圖找人，滾輪、雙指或 **E / Q** 縮放。先用上衣顏色篩選，再放大確認帽子顏色。
4. 準星永遠在畫面中央。注意準星下方的距離、飛行時間和風偏，按 **SPACE** 或右下角按鈕開火。
5. 打中非致命部位，噁男會倒地，只能在地上緩慢爬行，比較好完成委託人指定的順序。
6. 指定部位全部打中就自動結算，不一定要打死；也可以按「收工撤離」依完成度提早結算。結算視窗可以收起，看清楚噁男最後的樣子。
7. 剩下 30 秒會響起警示音，之後倒數聲越來越快。按 **M** 開關音效。

暗網終端的「檔案」頁有完整的背景故事與操作說明。

## 技術

- 純前端：HTML + CSS + 原生 JavaScript，**不需要建置工具**。
- 地圖：[Leaflet](https://leafletjs.com/) + [內政部國土測繪中心](https://maps.nlsc.gov.tw/) 正射影像（WMTS 圖磚服務）。
- 路網：[OpenStreetMap](https://www.openstreetmap.org/) 資料，事先用 Overpass API 下載各行政區的區界與道路，壓縮後放在 `data/`，遊戲執行時不需要連到 OpenStreetMap。
- 人物：程式產生的 SVG 俯視人形，外觀與命中判定使用同一份部位資料，看到的就是打得到的。
- 音效：Web Audio API 即時合成（槍聲、街道回音、拉栓上膛、倒數計時），沒有音效檔。
- 存檔：瀏覽器 `localStorage`。

## 在自己的電腦上執行

下載或 clone 專案後，在專案資料夾用附的極簡伺服器開啟（需要 Node.js，不用安裝任何套件）：

```bash
node tools/serve.mjs
```

然後用瀏覽器打開 http://localhost:8765/

> 其他靜態伺服器也可以用。不過在部分 Windows 環境下，`python -m http.server` 傳送較大的檔案會被截斷，造成某些行政區的路網載入失敗，所以建議用上面的方式。

## 更新街道資料

各行政區的路網存在 `data/<行政區>.js`。要重新下載（例如 OpenStreetMap 有更新）時，需要 Node.js 18 以上：

```bash
node tools/build-roads.mjs
```

只更新指定行政區：

```bash
node tools/build-roads.mjs xinyi daan
```

行人只會走在街道巷弄上：腳本只收一般道路、巷弄、人行道與行人穿越道，排除停車場車道、私人車道、隧道、騎樓與室內通道；步道和小徑只有在公園、綠地裡才收。

腳本會依序向 Overpass 公開伺服器查詢，每個行政區之間會暫停幾秒，避免造成伺服器負擔。

## 專案結構

```
index.html              遊戲本體（暗網終端、地圖、狙擊、彈道、委託、裝備、存檔）
js/
  audio.js              合成音效（槍聲、上膛、倒數）與音量設定
data/
  incidents.js          委託描述的組合素材（行為 × 地點 × 後續，可以直接增修）
  clients.js            委託人的暱稱與身分清單（可以直接增修）
  xinyi.js …            台北市 12 個行政區的區界與路網（由腳本產生，請勿手動編輯）
tools/
  build-roads.mjs       下載並壓縮各行政區路網的腳本
  serve.mjs             本機測試用的極簡靜態伺服器
images/
  favicon.svg           網站圖示
```
